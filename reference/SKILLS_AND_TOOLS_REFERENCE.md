# Skills, tools, repos, models and channels reference

A reading of every repo, site, tool, model and channel that came up while we designed Mills OS. Each item was opened from its own page and read only: nothing was installed, run or signed into. Prices, stars and versions are as read in October 2026 and will drift. Check before you rely on them.

**Verdicts.** ADOPT = use it (still through an intake audit, pinned). LAB = test first with fake or public data. E2 = only under a written exception. WATCH = not now, look again later. REFERENCE = a fact source only. SKIP = no use for us. E0 = never.

**Every verdict is a proposal for our setup, not a review of the project.** A SKIP often means "cloud-first" or "not our use case", not "bad".

Counts: ADOPT 81, LAB 126, E2 1, WATCH 142, REFERENCE 172, SKIP 199, E0 1. Items: 722. Video lessons: 1029 (in `video_lessons.tsv`). The full data for filtering is in `skills_and_tools.tsv`.
